# SpoiledZ
SpoiledZ is a minecraft mod addon for a seasons mod and adds spoilage to food items.

### Installation
SpoiledZ is a mod built for the [Fabric Loader](https://fabricmc.net/). It requires [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api), [Cloth Config API](https://www.curseforge.com/minecraft/mc-mods/cloth-config) and [Fabric Seasons](https://www.curseforge.com/minecraft/mc-mods/fabric-seasons) or [Serene Seasons](https://www.curseforge.com/minecraft/mc-mods/serene-seasons) to be installed separately; all other dependencies are installed with the mod.

SpoiledZ is a mod built for both the [Fabric Loader](https://fabricmc.net/) and [NeoForge](https://neoforged.net/).

- **Fabric:** requires [Fabric API](https://www.curseforge.com/minecraft/mc-mods/fabric-api), [Cloth Config API](https://www.curseforge.com/minecraft/mc-mods/cloth-config) and [Fabric Seasons](https://www.curseforge.com/minecraft/mc-mods/fabric-seasons) or [Serene Seasons](https://www.curseforge.com/minecraft/mc-mods/serene-seasons) to be installed separately.
- **NeoForge:** requires [Cloth Config API](https://www.curseforge.com/minecraft/mc-mods/cloth-config) and [Serene Seasons](https://www.curseforge.com/minecraft/mc-mods/serene-seasons) to be installed separately.
